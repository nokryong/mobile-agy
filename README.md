# Mobile-agy

Android에서 Antigravity와 대화하고 프로젝트를 작업할 수 있는 앱입니다. 파일과 이미지를 첨부해 질문하고, 프로젝트 파일을 살펴보거나 수정할 수 있습니다.

[최신 버전 다운로드](https://github.com/nokryong/mobile-agy/releases/tag/v0.1.3)

## 주요 기능

- **대화**: 모델 선택, 실시간 답변, 응답 중지, 저장된 대화 이어가기
- **첨부**: 파일·이미지·PDF 첨부와 프로젝트 파일 멘션
- **프로젝트**: 폴더 연결, 파일 탐색, 프로젝트 읽기·수정, 터미널
- **작업 권한**: 대화만 하기, 프로젝트 읽기, 프로젝트 수정 중 선택하고 변경 작업 승인
- **맞춤 설정**: 모든 대화에 적용할 개인 지침, 화면 테마와 글자 크기
- **휴대폰에서 사용**: 음성 받아쓰기, 플로팅 대화, 작업 완료·승인 요청 알림

## 설치

ARM64 기반 Android 10 이상 기기가 필요합니다.

1. [릴리스 페이지](https://github.com/nokryong/mobile-agy/releases)에서 `mobile-agy-0.1.3-arm64.apk`를 다운로드합니다.
2. 다운로드한 APK를 열고 Android 설치 안내를 따릅니다. 설치가 차단되면 APK를 연 앱의 설치 권한을 허용합니다.
3. Mobile-agy를 실행합니다.

현재 저장소는 비공개입니다. 다운로드하려면 저장소 접근 권한이 있는 GitHub 계정으로 로그인해야 합니다. 업데이트도 릴리스 페이지에서 APK를 받아 설치해 주세요.

## 처음 시작하기

1. 설정에서 앱 내 Linux 환경을 설치하고 활성화합니다.
2. 계정 설정에서 Antigravity CLI를 설치하고 Google 계정으로 로그인합니다.
3. 로그인 후 상태를 새로고침하고 사용할 모델을 선택합니다.
4. 메시지를 입력해 대화를 시작합니다. 프로젝트를 작업하려면 폴더를 연결하고 작업 권한을 선택합니다.

대화 입력란 아래의 모델 이름을 누르면 **작업 권한** 바로 아래에서 **승인 방식**을 바꿀 수 있습니다. 기본값은 **승인 받기**입니다. **모두 허용**을 선택하면 현재 대화에서 허용된 범위의 변경 작업을 매번 확인하지 않고 진행합니다.

첨부 버튼으로 파일이나 이미지를 추가할 수 있습니다. PDF는 페이지 단위로 열람하며, 첨부한 원본 파일은 그대로 보관됩니다. 알림을 받으려면 Android 알림 권한을 허용해 주세요.

현재 사전 공개 버전으로, Android 실기기 동작은 아직 검증되지 않았습니다.
