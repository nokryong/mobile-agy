파일을 첨부해 질문하고, 개인 지침을 적용해 대화할 수 있습니다.

## 새로운 기능

- 파일·이미지 첨부와 프로젝트 파일 멘션
- PDF 페이지 열람
- 모든 대화에 적용할 개인 맞춤 지침
- 작업 완료·실패 알림
- 새 앱 아이콘과 로고

첨부 원본은 그대로 보관됩니다. 첨부한 파일은 해당 대화에서만 사용할 수 있습니다.

## 설치 및 업데이트

ARM64 기반 Android 10 이상에서 아래의 `mobile-agy-0.1.1-arm64.apk`를 설치하세요. 0.1.0 사용자는 기존 앱 위에 설치해 업데이트할 수 있습니다.

Android 실기기 동작은 아직 검증되지 않은 사전 공개 버전입니다. 비공개 저장소이므로 다운로드에는 저장소 접근 권한이 있는 GitHub 계정이 필요합니다. 앱 내 업데이트 목록에 표시되지 않으면 이 페이지에서 APK를 다운로드해 주세요.
