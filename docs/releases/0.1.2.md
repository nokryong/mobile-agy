## 변경 사항

- 답변과 작업 상태에 표시되던 캐릭터 이모티콘 및 관련 설정 제거
- 플로팅 대화와 답변 표시의 아이콘을 앱 로고로 통일
- 일부 화면에서 스타일과 로고가 제대로 표시되지 않던 문제 수정

## 설치 및 업데이트

ARM64 기반 Android 10 이상에서 아래의 `mobile-agy-0.1.2-arm64.apk`를 설치하세요. 이전 버전 사용자는 기존 앱 위에 설치해 업데이트할 수 있습니다.

Android 실기기 동작은 아직 검증되지 않은 사전 공개 버전입니다. 비공개 저장소이므로 다운로드에는 저장소 접근 권한이 있는 GitHub 계정이 필요합니다. 앱 내 업데이트 목록에 표시되지 않으면 이 페이지에서 APK를 다운로드해 주세요.
