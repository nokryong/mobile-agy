Android에서 Antigravity를 사용할 수 있는 Mobile-agy의 첫 사전 공개 버전입니다.

## 주요 기능

- Google 계정으로 로그인하고 사용할 모델 선택
- 실시간 답변과 응답 중지
- 대화 저장 및 이어가기

## 설치

ARM64 기반 Android 10 이상에서 아래의 `mobile-agy-0.1.0-arm64-debug.apk`를 다운로드해 설치하세요. 앱 설정에서 Linux 환경과 Antigravity CLI를 설치한 뒤 Google 계정으로 로그인하면 시작할 수 있습니다.

파일 첨부는 이후 버전에서 지원합니다. Android 실기기 동작은 아직 검증되지 않은 사전 공개 버전입니다.

비공개 저장소이므로 다운로드에는 저장소 접근 권한이 있는 GitHub 계정이 필요합니다.
